# Ķepatiņa — мобильное приложение для ухода за питомцами

Приложение на React + Capacitor. Это **настоящее мобильное приложение** (Android / iOS), а не сайт:
оно устанавливается на телефон со своей иконкой и названием **Ķepatiņa**, работает без интернета,
а напоминания приходят как обычные уведомления телефона — даже когда приложение закрыто.

Всё, что было связано с Lovable, удалено (серверная часть, служебные файлы, зависимости, скрипты).

## Дневник и документы

- В «Альбоме воспоминаний» можно сохранять датированные события, заметки, фотографии и видео.
- В «Документах» можно хранить медицинские записи, результаты анализов, прививки и договоры об усыновлении, а также связывать документ с визитом или прививкой в медкарте.
- Содержимое файлов хранится на устройстве в IndexedDB; файлы не синхронизируются между устройствами и не входят в экспорт данных. Синхронизируются только записи и описания.
- Размер одного файла — до 50 МБ. Удаление питомца удаляет его дневник, документы и связанные локальные файлы.

## 1. Подключить Supabase (аккаунты и синхронизация)

Supabase нужен только для входа в аккаунт, сохранения данных в облаке и «семьи».
Без него приложение тоже работает — данные хранятся на телефоне.

1. Откройте проект в [supabase.com](https://supabase.com) → **Project Settings → API**.
2. Скопируйте **Project URL** (вида `https://abcdxyz.supabase.co`) и вставьте в файл `.env`:
   ```
   VITE_SUPABASE_URL=https://ВАШ-ПРОЕКТ.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
   ```
   В приложение кладётся **только publishable-ключ**. **Secret-ключ (`sb_secret_...`) в приложение
   нельзя** — любой может достать его из установленной программы и получить полный доступ к базе.
3. Откройте **SQL Editor → New query**, вставьте всё из файла `supabase/schema.sql` и нажмите **Run**.
   Это создаст таблицы и правила доступа. Повторно запустите этот файл после обновления приложения,
   чтобы установить новые таблицы и политики (в том числе семейный чат).
4. **Authentication → Providers → Email**: выключите **Confirm email**. Так регистрация в приложении
   сразу выполняет вход (ссылка из письма не умеет открывать приложение).

## 2. Проверить на компьютере

```
npm install
npm run dev
```
Откройте адрес из терминала в браузере (лучше в режиме телефона: F12 → значок телефона).

## 3. Собрать приложение для Android

### Вариант А — без Android Studio (через GitHub)
1. Загрузите проект в новый репозиторий на GitHub.
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**, добавьте
   `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`.
3. Вкладка **Actions → Build Android APK → Run workflow**. Через ~10 минут внизу страницы запуска
   появится файл **Kepatina-debug-apk** — внутри `app-debug.apk`. Скопируйте его на телефон и установите
   (разрешите установку из неизвестных источников).

### Вариант Б — на своём компьютере
Нужны Node.js 22 и [Android Studio](https://developer.android.com/studio).
```
npm install
npm run android:init     # создаёт папку android с иконкой, названием и разрешениями
npm run android:open     # открывает проект в Android Studio → кнопка ▶ Run
```
После любых изменений в коде: `npm run sync`.
Если Android/iOS-проект уже создан до добавления семейных голосовых сообщений, один раз обновите
нативные разрешения: `node scripts/patch-android.mjs` и `node scripts/patch-ios.mjs`, затем выполните
`npm run sync`.

### Публикация в Google Play
Нужен аккаунт разработчика Google Play (разовый взнос $25) и подписанный **AAB**:
Android Studio → **Build → Generate Signed Bundle / APK → Android App Bundle**.
Сохраните файл ключа (`.jks`) и пароль в надёжном месте — без них нельзя обновлять приложение.

## 4. iOS (iPhone)
Нужен Mac с Xcode и аккаунт Apple Developer ($99/год).
```
npm install
npm run ios:init
npm run ios:open        # Xcode → выберите Team → Run
```

## 5. Название, иконка, идентификатор
- Название: `capacitor.config.ts` → `appName` («Ķepatiņa»).
- Идентификатор приложения (нельзя менять после публикации): `appId` = `lv.kepatina.app`.
- Иконка и экран загрузки: папка `assets/` (`icon-only.png`, `icon-foreground.png`,
  `icon-background.png`, `splash.png`, `splash-dark.png`). Замените файлы и выполните `npm run assets`.

## Что изменено по сравнению с версией из Lovable
- Убран серверный рендеринг (TanStack Start/Nitro) — теперь это обычное клиентское приложение,
  которое собирается в статические файлы и упаковывается Capacitor.
- Удалены: пакеты и конфиги Lovable, `.lovable/`, `AGENTS.md`, `bunfig.toml`, `bun.lock`,
  отчёты об ошибках Lovable, перенаправление авторизации Lovable, адрес `*.lovable.cloud` в `.env`.
- Web Push с сервером заменён на **локальные уведомления телефона**: напоминания и приём лекарств
  планируются прямо на устройстве (`src/lib/notify-plan.ts`, `src/lib/native/notifications.ts`).
- Шрифты теперь встроены в приложение (раньше грузились с Google Fonts), поэтому всё работает офлайн.
- Кнопка «Назад» на Android работает как в обычных приложениях; поддержаны безопасные зоны и статус-бар.
- Поиск ближайшей клиники использует нативную геолокацию; «Поделиться» открывает системное меню.
- QR-жетон для потерянного питомца по умолчанию содержит читаемый текст с контактами владельца
  (читается любым сканером, сайт не нужен). Если у вас есть сайт, укажите его в `VITE_PUBLIC_WEB_URL`.

## Известные ограничения
- Печать / экспорт в PDF (медкарта, паспорт, жетон) в приложении недоступны — используйте «Поделиться».
- Android 12+: точное время уведомлений может сдвигаться на несколько минут, если у приложения нет
  разрешения «Будильники и напоминания». iOS хранит не более 64 запланированных уведомлений —
  приложение всегда планирует ближайшие 60 и обновляет их при каждом запуске.
- Первая сборка не тестировалась на реальном устройстве; проверьте уведомления, фото и геолокацию.
